# .github

The organization repository for MGconsulting. It holds the content GitHub
surfaces organization-wide:

- `profile/README.md` — the organization profile, shown on
  https://github.com/MGconsulting.
- Default community health files (`SECURITY.md`, `CONTRIBUTING.md`,
  `LICENSE`) inherited by every public repository that does not define its
  own.

Private repositories inherit their defaults from the private
`.github-private` repository instead.
